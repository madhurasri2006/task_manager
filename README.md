# Task Manager Application

🚀 **Live Demo:** https://task-manager-1-o2mz.onrender.com

## Project Description
A web-based application to manage and organise daily tasks.

## Technologies Used
- React.js
- Node.js
- Express.js
- MongoDB Atlas
- Bootstrap
- Axios

## Features
- Add tasks
- View tasks
- Update tasks
- Delete tasks
- Manage task status
- Track task progress

## Deployment
Frontend and backend deployed using Render.
Database hosted on MongoDB Atlas.
